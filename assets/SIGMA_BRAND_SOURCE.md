# Sigma Code brand source

`sigma-code-mark.png` is copied from the maintained Sigma core repository at
`assets/sigma-code-mark.png`. It is the canonical source for the downstream
desktop, web, and mobile icon exports.

Run `pnpm icons:export` after updating the canonical image. The generator is
dependency-free and writes every packaged PNG, ICO, and ICNS rendition from
that source without altering the artwork.
